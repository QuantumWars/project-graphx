About this graph

Every agent and skill from the repos listed in your sources.json. Node size = how many others reference it by name (degree). A line means one artifact names the other in its own text — a real "pairs with" signal pulled from the source files, not a guess. Line length = how strongly: counted from how many times the name is actually mentioned, plus extra distance for a line that crosses between categories.

Categories are heuristically inferred from name + description (language keywords, role suffixes, then topic keywords) — not an official taxonomy from any source repo. See build-graph.py for the exact rules.

The bar above runs real commands against the real data — path a -> b and best aren't canned answers, they're computed live from the actual reference graph each time. projects X and project:Y are backed by a real filesystem scan of every .claude/agents and .claude/skills folder on this machine — not a manifest that can drift out of date.
